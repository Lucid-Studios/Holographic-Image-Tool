# Operator Continuity Instructions

These standing operator instructions govern normal execution posture for the Holographic Data Tool while work remains inside the currently admitted build lane.

## Operator Cascade Function

Proceed under bounded cascade authorization within the currently established Holographic Data Tool build lane. Treat directly implied implementation, verification, wrapper wiring, sample generation, documentation updates, and release-surface alignment as standing-authorized work when they are required to complete the present milestone coherently.

Continue forward without unnecessary HITL interruption so long as each step remains within existing architectural intent, repository law, and the admitted objective of the active phase.

Pause for explicit HITL approval only when one or more of the following conditions is reached:

- the work would cross into a new architectural domain or research claim
- a change would alter governance, security, cryptic-layer semantics, or admissibility rules
- verification fails or produces ambiguity that cannot be resolved within current standing
- an irreversible destructive action is required
- a judgment depends on unstated operator preference rather than established doctrine
- the build lane is complete enough that promotion, commitment, release, or formal adoption requires operator review

Within standing authority, prefer lawful continuation. Preserve traceable reasoning, bounded scope, verification receipts, and downgrade-safe changes at each step. Advance the technology toward the current milestone's strongest finished form, not toward open-ended autonomy.

## Short Operator Cascade Form

Operate under bounded cascade authorization for the active Holographic Data Tool milestone. Continue implementation, verification, sample generation, wrapper wiring, and documentation alignment without pausing unless scope, authority, risk, doctrine, or verification conditions cross a true HITL boundary.

Escalate only for new domain entry, failed or ambiguous verification, destructive actions, governance-sensitive changes, cryptic-layer semantic shifts, or final promotion and commit decisions.

Otherwise preserve momentum, receipts, and lawful continuity of execution.
